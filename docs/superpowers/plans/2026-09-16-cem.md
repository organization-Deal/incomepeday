# CEM QR-Box integration

Preserve the existing dashboard and only replace existing, explicitly mapped LO rows.
Verified 25 unique exact boxing-name matches; 17 also have one machine, THB and
calendar-day closing. Exclude other currencies/custom closing until reconciled.
Never combine EQLink and CEM for the same LO code.

CEM provides closed daily reports plus a separate current-day summary. Validate
complete unique days, branch/machine identity, currency, closing mode, and current
summary date. Never infer status from money or assume missing data is zero.
Reuse the existing daily/round merger and historical GAS statuses; expose only LO
codes, revenue and current status to the browser.

A whole CEM fleet plus EQLink exceeds the free Worker per-request outbound budget.
The monthly API supplies a CEM batch manifest. The client reads batches of five
(sequential batches, two machines per batch in flight), then atomically merges
all batches. Each batch performs at most 16 upstream requests: refresh + 3/device.
A failed batch fails the month load, with the existing error UI. No partial totals.
Cache validated batches 10 minutes/current or 6 hours/past, keyed by configuration.
Fresh bypasses all caches; manifest version prevents mixing changed mappings.

Use CEM_REFRESH_TOKEN and CEM_MAPPING Worker secrets. Live verification showed
refresh can invalidate an earlier bearer, so a per-login-session SQLite Durable
Object owns token rotation and serializes complete CEM read operations. It reuses
the bearer until 60 seconds before expiry and durably saves rotated refresh tokens
before reads. Queues are bounded to eight and waiting work expires after fifteen seconds.
Each operation has a shared 45-second deadline including token refresh.
No blockConcurrencyWhile around network I/O and no background refresh alarms.
Authenticate once outside normal reads (CEM limits signed-in devices). Rotated
tokens persist across eviction; inactive/revoked sessions still require authorized
login renewal. No password fallback loop, session eviction or machine commands.
The local setup script renews only the ignored local secret, not production.
History uses one yearly report per represented year, maximum 36 monthly entries, same mapping.
